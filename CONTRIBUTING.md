## Editing agents

Agents live in `agents/*.md`. Some roles also ship effort variants, such as `reviewer-low` and `reviewer-xhigh`, because the `Agent` tool has no per-call effort and an agent's effort is fixed by its file.

- Edit the base file, for example `agents/reviewer.md`. Never edit a `-low` or `-xhigh` file by hand: each starts with a `GENERATED by playbook agents gen` comment and is rewritten from its base.
- To add or drop a variant, edit the `VARIANTS` table in `src/agents/variants.rs`.
- Run `playbook agents gen` to write the variants. It is idempotent and deterministic.
- Run `playbook agents check` before you push. It fails on a stale or hand-edited variant, a variant whose base is missing, and a generated file with no `VARIANTS` entry. CI runs it too.

See [Authoring agents](docs/authoring/02-authoring-agents.md) for the frontmatter rules.
